# Hipica Management

Plugin básico para gestionar hípicas en WordPress.

## Funcionalidades
- Roles personalizados para **alumnos** y **profesores**.
- Tipos de contenido: caballos, pistas, fichas de alumnos, clases y reservas.
- Taxonomía "estado del caballo" para indicar su disponibilidad.
- Campo "nivel/color" en el perfil de usuario para filtrar clases.
- Shortcode `[hipica_clases]` que lista las clases disponibles para el usuario y permite reservar.
- Control simple de aforo mediante un meta campo `max_alumnos` en cada clase.

Este plugin es solo un punto de partida sobre el que añadir pagos, notificaciones y otras funciones más avanzadas.
